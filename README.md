# 🛒 Kantin Sipariş Sistemi

Bu proje, nesne yönelimli programlama (OOP) ve temel Python yapıları kullanılarak geliştirilmiş, Terminal tabanlı bir kantin sipariş uygulamasıdır. 

Kullanıcılar kantindeki güncel menüyü görüntüleyebilir ve istedikleri ürün için sipariş oluşturabilirler.

---

## 🚀 Özellikler

- **Menü Görüntüleme:** Kantinde satılan ürünleri ve fiyatlarını liste halinde gösterme.
- **Sipariş Verme:** Kullanıcının girdiği ürün adına göre stok/menü kontrolü yapıp siparişi tamamlama.
- **Hata Kontrolü:** Menüde bulunmayan ürünler veya geçersiz seçenekler için kullanıcıyı bilgilendirme.
